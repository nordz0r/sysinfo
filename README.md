**sysinfo** показывает ОС, ядро, процессор, uptime, load average, RAM, swap,
занятость дисков и IP-адреса. Вывод остаётся на английском, чтобы одинаково
читаться в терминалах на серверах и роутерах.

- **Быстрый запуск:** системные утилиты, без Python, Node.js и обращения к сети при локальном запуске.
- **Наглядные ресурсы:** полоски заполнения и цветовые предупреждения о нехватке места.
- **Компактный вывод:** до четырёх файловых систем и трёх интерфейсов по умолчанию; для OpenWrt показываются все активные IPv4-интерфейсы.
- **Установка по желанию:** без ключей скрипт выполняется сразу; `--install` настраивает удалённый автозапуск, локальная копия не сохраняется.

## Быстрый старт

```sh
curl -fsSL https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh
```

Или через `wget`:

```sh
wget -q -O - -T 5 https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh
```

Используйте доверенный источник и просмотрите код перед запуском. При передаче
через pipe неполная загрузка может привести к выполнению частичного скрипта;
сначала скачать файл и проверить его безопаснее.

## Автозапуск

### Удалённый запуск при входе

Основная команда скачивает скрипт из GitHub и настраивает автозапуск в один шаг:

```sh
curl -fsSL https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh -s -- --install
```

Она не сохраняет локальную копию. При каждом интерактивном входе настроенный
профиль загружает свежий скрипт с GitHub и передаёт его в `sh`. Сообщение о
настройке появляется после первоначальной загрузки: её выполняет команда
`curl`/`wget` до запуска скрипта, поэтому скрипт не может сообщить о ней.

**OpenWrt:**

```sh
wget -q -O - -T 20 https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh -s -- --install
```

Профиль выбирается по имени оболочки в `SHELL`: для Bash используется
`~/.bashrc`; иначе, в том числе если `SHELL` не задана, — `~/.profile`.
Настройка проверяет загрузчики и выбирает `curl`, а при его отсутствии — `wget`.
Если оба отсутствуют, профиль не меняется. Команда запускается только в
интерактивной оболочке, когда stdin и stdout подключены к терминалу; `ssh host
command`, `scp`, cron и перенаправленный вывод не запускают сводку. Ошибка
загрузки не прерывает вход в оболочку, но неполная загрузка может выполнить
частичный скрипт.

`~/.profile` — стандартный профиль входа POSIX, но его читает не каждая оболочка.
Если используемая оболочка не читает этот файл или не поддерживает POSIX shell
hooks, настройте подходящий файл вручную.

### Локальный режим (по желанию)

Для работы без сети при последующих входах сохраните скрипт в
`~/.local/bin/sysinfo.sh` и сразу настройте автозапуск локальной копии:

```sh
curl -fsSL https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh -s -- --install --local
```

На OpenWrt:

```sh
wget -q -O - -T 20 https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh -s -- --install --local
```

Локальная копия не обновляется автоматически. Чтобы получить обновление,
повторите команду установки.

### Через прокси

Для удалённого варианта укажите прокси для первоначальной загрузки и будущих
запусков; замените `proxy.example.com:3128` на адрес своего прокси:

```sh
sysinfo_proxy='http://proxy.example.com:3128'; curl -fsSL --proxy "$sysinfo_proxy" https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh -s -- --install --proxy "$sysinfo_proxy"
```

Адрес из `--proxy` сохраняется в команде выбранного загрузчика. Для первой
загрузки через `wget` задайте `https_proxy` и `http_proxy`:

```sh
sysinfo_proxy='http://proxy.example.com:3128'; https_proxy="$sysinfo_proxy" http_proxy="$sysinfo_proxy" wget -q -O - -T 20 https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh -s -- --install --proxy "$sysinfo_proxy"
```

При повторной настройке передавайте `--proxy` снова; без него используются
обычные настройки прокси из окружения. Для совместимости с обоими загрузчиками
используйте `http://`-прокси; адрес `https://` требует `curl`.

### Переход со старой версии

В старых версиях команда `setup` настраивала профиль отдельно. В текущей версии
используйте `--install` для удалённого автозапуска либо `--install --local` для
установки локальной копии и её автозапуска за один шаг. Повторная установка
заменяет распознанные записи sysinfo только в профиле, выбранном по `SHELL`;
настройки других файлов профиля не меняются. Существующие настройки выбранного
профиля сохраняются.

Перед первым изменением профиль сохраняется в резервную копию с суффиксом
`.sysinfo.bak`; существующая копия не перезаписывается. Повторная установка не
создаёт дубли. Символьные ссылки вместо файла профиля остаются без изменений.
Удалите блок между `# >>> sysinfo >>>` и `# <<< sysinfo <<<` включительно,
если хотите убрать автозапуск вручную.

После запуска скрипт сообщает о выполненном действии и затронутом файле или
профиле. Эти сообщения выводятся по-русски, если первое непустое значение среди
`LC_ALL`, `LC_MESSAGES` и `LANG` начинается с `ru_RU` (допускаются суффиксы
`.кодировка` и/или `@модификатор`); в остальных случаях — по-английски. Сводка
системы всегда остаётся на английском.

Удаление настроенного автозапуска и управляемой локальной копии:

```sh
curl -fsSL https://raw.githubusercontent.com/nordz0r/sysinfo/master/sysinfo.sh | sh -s -- --uninstall
```

Для OpenWrt замените `curl` на `wget -q -O - -T 20` и оставьте тот же URL.

Удаление безопасно при повторном запуске; оно не затрагивает посторонний текст
профиля и сохраняет сами каталоги.

## Параметры

| Команда / ключ | Действие |
| --- | --- |
| `--install` | Настроить удалённый автозапуск; локальный скрипт не сохраняется. |
| `--install --local` | Сохранить `~/.local/bin/sysinfo.sh` и настроить его автозапуск. |
| `--uninstall` | Удалить управляемый автозапуск и установленную локальную копию, если она есть. |
| `--proxy URL` | Вместе с `--install` сохранить прокси для удалённого автозапуска. |
| `--interactive-only` | Выводить сводку только при stdin/stdout, подключённых к терминалу. |
| `--details` | Показать все выбранные локальные файловые системы и IPv4-интерфейсы. |
| `--all-interfaces` | Показать все IPv4-интерфейсы, включая виртуальные. |
| `--color` / `--no-color` | Принудительно включить или выключить ANSI-цвета. |
| `--help` | Показать справку. |
### Полоски и цвета

| Заполненность | Цвет |
| --- | --- |
| Менее 80% | Зелёный |
| От 80% до 94% | Жёлтый |
| От 95% | Красный и знак `!` |

Проценты берутся из `df`, с учётом доступного места и резерва файловой системы.
Размеры не складываются; повторные монтирования скрываются. Цвет автоматически
отключается при перенаправлении вывода, `TERM=dumb` или установленном `NO_COLOR`.

В UTF-8 используются ровные символы `█`/`░`, иначе — `=`/`-`.
На OpenWrt без настроенной локали UTF-8 определяется по типу терминала;
переопределение доступно через `SYSINFO_UTF8=1` или `SYSINFO_UTF8=0`.
Длина разделителей учитывает вывод и ширину терминала (`COLUMNS`).

## Совместимость

| Среда | Особенности |
| --- | --- |
| Linux / Debian | Данные из `/proc`, локальные диски через `df`, сеть через `ip` или `ifconfig`. Docker и другие служебные виртуальные интерфейсы по умолчанию скрыты. |
| OpenWrt / BusyBox | Достаточно `ash`, `awk`, `df` и `ip`; Bash не требуется. Показываются все активные IPv4-интерфейсы, SoC/ARM CPU и модель платы, если данные доступны. |
| macOS | Используются штатные `sysctl`, `vm_stat`, `sw_vers`, BSD `df` и `ifconfig`. |

Базовые зависимости — `sh`, `cat`, `uname`, `awk`, `df`. Для установки нужны
`mkdir`, `mktemp`, `chmod`, `mv` и `rm`. Локальный запуск не требует `curl`/`wget`;
при отсутствии обоих скрипт подсказывает команду установки загрузчика.
Для настройки автозапуска требуются `cp`, `cmp` и `mktemp`; Bash не нужен.

На OpenWrt команда автоматической настройки выше работает с `wget` и штатным
`ash` (`sh`). `/overlay` не дублирует корневую файловую систему, `/tmp`
показывается отдельно, неизменяемый squashfs пропускается. Настройка выбирает
`~/.profile`, если `SHELL` не указывает на Bash.

macOS проверена на образцах вывода системных команд; проверка на настоящем Mac
остаётся необходимой. Расчёт RAM через `vm_stat` — оценка занятости, не показатель
memory pressure из Activity Monitor.

## Разработка

```sh
sh sysinfo.sh
sh sysinfo.sh --details
python3 -m unittest discover -s tests -v
```

Тесты проверяют Linux, образцы macOS/OpenWrt, интерактивный Bash с терминалом,
молчаливый неинтерактивный запуск, повторную установку и удаление, миграцию
старого автозапуска, загрузку через прокси, резервную копию профиля и отказы записи.

<details>
<summary><strong>Дополнительные проверки</strong></summary>

Проверка на настоящих апплетах BusyBox:

```sh
SYSINFO_TEST_SH=/path/to/busybox-bin/sh \
SYSINFO_TEST_AWK=/path/to/busybox-bin/awk \
python3 -m unittest discover -s tests -v
```

ShellCheck для точки входа и встроенного кода:

```sh
shellcheck sysinfo.sh
awk 'BEGIN { print "sysinfo_payload=" } /^sysinfo_payload=\$\(cat/ { body=1; next } /^SYSINFO_PAYLOAD$/ { exit } body' sysinfo.sh | shellcheck -s sh -
```

</details>
